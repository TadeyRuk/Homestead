# AI use record

How AI tools were used to make Homestead. This is the project's AI metadata, as the 2026 Space Apps rules ask for code and data ("acknowledge SI generation in descriptive text and metadata"). The README's "AI use" section is the short version.

The game concept, its design and the proposal plan are the team's own. AI was not used to come up with the idea.

## Code

The game's code was written with AI assistance (Claude Code). Every change went through a pull request that a team member merged, and a person played the game after each merge.

## Music

The game's music was made with AI assistance.

## Art and video

- **Game art** is drawn in code and is labelled as made with AI. The game will show a visible "Made with AI assistance" label in a corner of the screen.
- **The proposal mocks and walkthrough** (`proposal/refs/`, `proposal/walkthrough.html`) are AI-assisted and each is labelled "AI-assisted mock, not final art".
- **The demo video:** any AI-made frames carry a visible watermark.
- No AI-made content uses NASA logos, flags or mission identifiers.
